# Live session mode

When the DM says a session is running, behave by these rules until told otherwise.
This file overrides normal verbosity. Read `_dm/ACTIVE.md` for where the party actually is.

## Speed over completeness

- The DM is reading this with players waiting.
- Answer the question asked. Do not add context, caveats, or alternatives unless asked or if its really meaningful.
- No preamble. No "great question". No summarising what was just asked.
- If something needs a longer answer, give the short answer first and offer the long one.

## Rules questions

The DM has explicitly asked for a second voice on rules. When asked:

1. Give the 2014 answer.
2. Give the source (`Rules/SRD/...` path, or PHB/DMG page if it is not in the SRD).
3. Stop talking.

If the rule is genuinely ambiguous in 2014, say so in one line and give the most common reading.
Never resolve an ambiguity by reaching for the 2024 version.

## Improvisation requests

When asked for an NPC, a room, a complication, or a monster on the spot:

- Danish for anything read aloud. English for anything mechanical.
- Match the tone of the current location note.
- Write it to the right folder with `status: unverified` and tell the DM in one line.
- Give the DM only what he needs at the table right now — for a monster that is
  the name, AC, and HP. Everything else goes in the file to be finished later. 

## Never, during a session

- Never contradict `_dm/ACTIVE.md` without flagging it.
- Never suggest the DM pause to reorganise the vault.
- Never write to `Combat/State.md`. The tracker owns that file.
- Never retcon something a player has already acted on.

## After the session

The DM will say the session is over. Then switch back to normal mode and run the
post-session pass — see the command in `_dm/ACTIVE.md`.
