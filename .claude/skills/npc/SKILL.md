name: npc
description: Improvise a named NPC on the spot and write them to NPCs/.
---

The DM needs an NPC now.

1. Read the current location note and `_dm/ACTIVE.md` for setting and tone.
2. Check `NPCs/` first — if someone existing could plausibly fill the role, propose them
   instead of inventing a duplicate.
3. Create them: name, one-line role, a distinguishing physical detail, a want, and one
   thing they know that the party does not.
4. Write to `NPCs/<Name>.md` with `status: unverified` and an `aliases:` list including
   every name the table is likely to use.
5. Reply with three lines max — name, look, want. The DM will improvise the rest.

Description in Danish. Any mechanics in English.
