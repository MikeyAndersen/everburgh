---
name: rule
description: Answer a D&D 5e 2014 rules question. Use whenever the DM asks how a rule, spell, condition or ability works.
---

Answer the rules question. Order of authority:

1. `_dm/HOUSERULES.md` — if the table has ruled on it, that is the answer. Say it is a houserule.
2. `Rules/SRD/` — grep it. Cite the file path.
3. PHB/DMG/MM by page if it is not in the SRD. Say which book.
4. `Reference/` — the DM's own PDFs.

Format: the answer, then the source, then stop. Two or three sentences.

- 2014 rules only. If you know the 2024 version differs, do not mention it unless asked.
- If genuinely ambiguous in 2014, say so in one line and give the most common reading.
- Never invent a rule to be helpful. "That needs a houserule" is a valid answer.
