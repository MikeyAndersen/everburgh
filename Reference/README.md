# Reference

Læg dine PDF'er her — regelbøger, adventures, inspirationsmateriale.

Claude Code må læse alt i denne mappe frit til opslag og inspiration. Indholdet er ikke
kanonisk for kampagnen med mindre det bliver skrevet ind i `Lore/`, `Bestiary/` eller
`Locations/`.

Foreslået inddeling:

```
Reference/
  Rulebooks/
  Adventures/
  Inspiration/
```
